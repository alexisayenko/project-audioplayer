# Genre lineage: what emerged from what

> Alex: are "genres/sub-genres L1..L4" and "what emerged from what" one diagram or two? Example: "Drum and bass formed out of the British breakbeat hardcore and breakbeat scenes of the early 1990s through an emerging field of jungle."

Decided 2026-10-21 (chat): two different relations over the same genre nodes.

| | Classification (exists) | Lineage (new) |
|---|---|---|
| Question | what kind is it | where did it come from |
| Shape | parents, equal parents, `fusion` flag, levels L1..L4 ([ADR-0037](../tech/decisions.md), [ADR-0038](../tech/decisions.md)) | directed `derived_from` edges carrying time |
| Time | none | decade or year range |

They cross: jungle is a drum and bass sub-genre today, yet an ancestor of drum and bass. Merging them would make one node ancestor and descendant in one tree. Lineage may also have many parents and revival loops, so it stays a separate relation. The existing `related` stays a loose "similar to" link.

## Proposal

- Optional per-genre `derived_from` list in the server data. Entry: source genre name, optional decade or year range, optional note or source link.
- Validated against the vocabulary (unknown names rejected).
- Cycles: reject by default; allowed only when the edge is marked `revival` (state the final choice in the ADR).
- Exposed additively in `/genres/vocabulary`; the legacy `/genres/graph` used by the Mac app stays unchanged.
- The Genres map gets a view toggle **Classification | Lineage**, same nodes and colours. Lineage draws directed arrows and can order nodes by decade.
