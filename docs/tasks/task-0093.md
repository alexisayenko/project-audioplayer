# Reference tracks per genre

> Alex (FT1, 2026-10-21/23): the "classical, iconic" tracks that defined a genre and that others used as references: golden standards; hearing one you can say "this is definitely this genre". Write an ADR and a task, analysis first, no code until he approves.

Decision record: [ADR-0044](../tech/decisions.md) (proposed). Status: analysis only, nothing built.

## Why

Alex tags songs "classical progressive house". Problems: "classical" clashes with classical music; one tag per genre explodes; a multi-genre song cannot say which genre it defines; it mixes a genre with a quality or role; no reason or rank; it only works for songs already in the library, and the most defining tracks may not be there.

## Proposal

- A per-genre `reference tracks` list in the shared genre catalogue, edited only by the owner (like the genre vocabulary and ADR-0039's Artist/Release catalogue). File: `server/data/genre_references.json`, `{genre: [entries]}`.
- Entry: `{artist, title, year?, role, note, source_url?, song_id?}`. `song_id` links a library song; the match is curated, not automatic (ADR-0039).
- Roles: `archetype` (definitely this genre: the etalon, typical sound), `origin` (first notable track of the style), `landmark` (others used it as a reference), `breakthrough` (brought the genre to a wide audience). Extend only with Alex's approval.
- A track may be a reference for several genres, with a different role in each. Entries not in the library are a wish list ("Add to library" later).

## UI sketch

- Genre info panel: "Reference tracks" section (play for library songs, "Add to library" for the rest, role badge, note).
- Song card: action "Mark as reference for..." (genre, role, note) and a small badge on reference songs.
- Library filter "Reference tracks only" and by role; maybe a "References" count column on the Genres Statistics tab.
- Used as the prototypes of the named feature space ([task-0070](task-0070.md), `prototypes`), for genre and song distance ([task-0064](task-0064.md)) and for the [etalon test](../tech/genre-terminology.md#the-etalon-test) of genre definitions.

## Conversion

One-time migration of Alex's "classical (genre)" tags into reference entries (role `archetype` by default, he reviews), then the tags are removed. Read-only count in the demo library copy (2026-10-23): 0 such tags (the only match is the genre "modern classical"); the real library is not checked.

Suggestions only, no scraping; always curated by Alex:
