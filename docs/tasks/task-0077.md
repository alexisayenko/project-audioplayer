# Gapless A-B loop

> Alex (2026-10-21): make the Studio A-B loop gapless. Replaces the timer-seek accuracy limit recorded in [task-0072](task-0072.md).

## Design

- While a loop is active and the playhead is inside the region, the region plays from a decoded `AudioBuffer` through an `AudioBufferSourceNode` (`loop = true`, `loopStart = A`, `loopEnd = B`): sample-accurate, no decoder seek.
- The source feeds the same shared gain and analyser chain as the `<audio>` element (`audio-graph.js`), so the visualizer works. The element's `MediaElementSource` is created once, as before; it is only rerouted through a mute gain. Volume and mute follow the element through the source's own gain.
- The `<audio>` element keeps playing silently in step (its timer-seek engine still wraps it), so the playhead, `timeupdate`, lock-screen state and the `ended` handling stay unchanged. The element is pulled back to the buffer position when it drifts by more than 0.12 s or overshoots the region.
- Decode: `fetch` of the audio file plus `decodeAudioData`, only when a loop is turned on, only up to 24 MB and 600 s (decoded PCM is about 100 MB per 5 min of stereo), and the buffer is freed when the loop is turned off or the song changes. Not the 12 MB peaks limit: that one is for a 1-channel reduction.
- "Preparing loop..." shows in the dock chip while it decodes. The timer engine loops meanwhile.
- Fallback to the timer engine, silently, on: no Web Audio, context not running, fetch or decode failure, file over the cap, song over the duration cap, playback rate other than 1. A failed song is not retried until the loop is turned off and on.
- Seek inside the region restarts the source there; a seek outside hands the sound back to the element; entering the region engages the buffer. A/B changes update `loopStart`/`loopEnd` live. Pause stops the source; play restarts it at the element position. Loop off leaves the element at the loop position.
- `player.loop` API unchanged (new read-only `buffered`, `preparing`); the dock "Loop A-B" chip is unchanged apart from the preparing note.
