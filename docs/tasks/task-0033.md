# Genre families follow Discogs genres

Replace the Genres map families with the 15 Discogs genres plus Other. Requirements: [genres.md](../specs/genres.md) (GEN-037 to GEN-042). Decision: ADR-0021 (accepted). Built 2026-10-16 (not deployed).

## Open points

- Building the table: 1. a script reading Discogs styles through the existing `DISCOGS_TOKEN` lookup; 2. a one-time import of the public Discogs genre and style list (recommended: no runtime dependency); the result is reviewed in git.
- Migration of colour assignments: map the old family names to the new ones (Folk, World, & Country becomes Folk, World, & Country; Folk and World merge there); until the design system export lands, reuse existing colours where names match.
- UI: outline and legend order is the fixed Discogs order (GEN-041); alternative, by song count.

- Input: the manual parent table `server/app/data/genre_parents.json` (GEN-045) also assigns families: a manually linked genre inherits its parent's family through the normal ancestor walk.

## Steps

1. Build `server/data/genre_families.json` from the Discogs styles; review.
2. Rewrite family resolution in `server/app/genre_graph.py` per GEN-038, keeping the umbrella rule (GEN-034).
3. Add the 16-colour family palette to the Electrophone design system; export; run `scripts/sync-design-system.py` (ADR-0009).
4. Update `web/js` outline, legend and colours; hide empty families.
5. Tests per GEN-042; update docs and CHANGELOG as it ships.

## Result

- Table: `server/data/genre_families.json` (about 690 lowercase Discogs styles and aliases, each under one genre; disco, acid jazz and new wave went to Electronic by the GEN-039 order rule at first). Test fixture `server/tests/fixtures/genre_graph_live.json`: 99.8% of songs resolve to a family (one song, "underground music", stays in Other; limit 5%).
- Genre cleanup 2026-10-16 (Alex, DN1; built, not deployed): reviewed overrides disco to Funk / Soul, new wave to Rock, acid jazz to Jazz; explicit entries for the kept subgenres and bare stored forms (electronic, dance, electronic dance, experimental, singer-songwriter, estrada, epic, trailer, liquid funk, euro disco, modern classical; TAG-076); new aliases (dnb, edm, euro pop, eurohouse, electronic pop, festival progressive house, festival trap, red disco; TAG-071), retags (appalachian folk, bard, west coast swing, romantic, psychedelic, nederpop, orchestral, alternative, indie, progressive with the per-song house/rock rule; TAG-075) and drops (popular, underground, club, cyberpunk; TAG-073); dystopian is retagged to darksynth (TAG-075); nu-nrg and uplifting trance added with manual parents (GEN-045). No new manual parent was needed: every kept subgenre already has a Wikidata parent edge (GEN-045 note). "underground" is dropped, so the last Other song of the fixture goes away at the next start.
- Colours: reused the existing 16-entry `--gf-*` palette in `web/genres.css` by family name (the names already matched); the order of the outline and legend uses `FAMILY_ORDER` in `web/js/genre-data.js`. Follow-up for the design system: the palette still lives in `genres.css`, not in `tokens.json`; add the 16 family colours there and re-export (GEN-040).
- Decided 2026-10-16 (Alex, DK1): the Discogs style becomes the second outline level; the strict vocabulary and the hybrid outline are in ADR-0023 and [task-0035](task-0035.md); this task's table is replaced there. Outline unchanged until task-0035 ships.
