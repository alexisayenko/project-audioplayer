# SoundHound as a catalog source

First step: verify the facts below against current Apple/vendor docs before building; they come from memory and are unverified.

Decision: parked. Revisit trigger: Alex uses SoundHound daily.

Findings (unverified): the only free route is pasting a SoundHound share link and reading its page metadata, which is fragile (page markup changes, no stable API). The Houndify platform is commercial and has no consumer history export. AudD and ACRCloud are paid and need audio clips uploaded to a third party; not recommended (privacy and cost).

If revived, scope: share-link metadata read as a metadata-only record, same Add flow as task-0007 and task-0012. Done when: a pasted share link saves a record, with the fragility shown as a clear error when the page cannot be read.
