# Genre vocabulary and style level

A strict canonical `genre:` vocabulary (Discogs genres and styles plus a reviewed extras file) and a hybrid Genres outline (Discogs genre, Discogs style, Wikidata subgenres). Requirements: [tags.md](../specs/tags.md) (TAG-077 to TAG-084) and [genres.md](../specs/genres.md) (GEN-046 to GEN-050). Decision: ADR-0023 (accepted). Builds on [task-0033](task-0033.md). Phases 1 to 3 built 2026-10-16 (deployed); phase 4 planned.

## Phases

- [x] 1. Data and validator: `server/data/genre_styles.json` (512 styles under the 15 genres, each name checked against the public Discogs search; source, terms and refresh in `server/data/README.md` and [deploy.md](../tech/deploy.md#genre-vocabulary), TAG-084) and `server/data/genre_extras.json` (65 extras with family and parent); validator tests (TAG-083) with the live-library fixture.
- [x] 2. Server: vocabulary loaded once (`app/genre_vocab.py`); out-of-list `genre:` writes answer 422 with suggestions (TAG-079) on `POST /songs` and `PATCH /songs/{id}`; suggestions from every lookup are narrowed silently; ALIASES and RETAGS targets are checked by tests; `GET /genres/vocabulary` serves the list; the startup migration keeps unmappable tags and writes `backups-genre-merge/review-<uid>.json` (TAG-082); `genre_families.json` is retired in favour of the new files (GEN-038 step 1); every graph node carries `style` for phase 3.
- [x] 3. Web (built and deployed 2026-10-16): genre picker with autocomplete in the song form and tag editor, no free text, 422 `unknown_genre` handled inline (TAG-080); hybrid outline with the style level and Wikidata nodes hung on their style (GEN-046 to GEN-050); GEN-036 kept as a fallback only. `GET /genres/vocabulary` also serves `aliases`. The "also under" family link of GEN-049 is not built.
- [ ] 4. iOS later: the same picker over the same list (`GET /genres/vocabulary`), after the web ships.

- Review of the extras file (65 entries; about 25 were planned: the rest are library tags that are real genres Discogs lacks) and of the unmappable-tag report after the first migration run on production (`backups-genre-merge/review-<uid>.json`; the live fixture predicts: aaron smith, joris, medley, music video, party, popcorn, skrux, ⚈⚈).
