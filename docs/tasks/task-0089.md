# Refresh listening statistics while Statistics is open

Keep listening statistics current while the Statistics screen remains open,
on both web and iOS. On web, refresh after the existing `plays-flushed` event
signals that play records were saved. In iOS, where the app does not post
`/plays`, observe server-side listening-stat changes only while Statistics is
visible. Refresh the displayed statistics without requiring navigation away
and back; do not change the desktop web player's mouse-oriented playback UX.
