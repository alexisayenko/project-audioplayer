# Studio Tools: harmonics lab extras

> Alex (2026-10-24): step 1 is only the synth; "the rest: create follow-up tickets".

Follow-up of [task-0106](task-0106.md). Nothing is built.

## Scope (all optional controls on the lab)

- Odd/even toggles: all, odd only, even only (H1 always sounds).
- Inharmonicity slider B: `f_n = n f0 sqrt(1 + B n^2)`; the spectrum bars move off the exact multiples and their labels show the real Hz.
- Time-decay envelope: a note that fades, with the higher harmonics fading faster than the lower ones.
- A4 reference from 415 to 466 Hz (default 440), used by the note picker and by the [note detector](task-0107.md).
- Note or keyboard picker: choose a note (name and octave) or press an on-screen keyboard key and the Frequency field follows.
- Presets: sine, triangle, sawtooth, square, piano-like. Each sets Hn, decay, odd/even and, for piano-like, B and the envelope.

## Open questions (recommendations, not decisions)

- A. Phases: a triangle has alternating signs and a square differs from a sawtooth in the waveform only through phase. Recommended: amplitudes only in this task (spectrum exact, waveform approximate for triangle), a phase option later.
- B. Envelope time constant: Recommended: tau_n = tau_1 / n, with tau_1 0.1 to 5 s; the steady tone of step 1 stays the default.
- C. B range? Recommended: 0 to 0.01, logarithmic slider, 0 = exact harmonics.
- D. Keyboard: one or two octaves, touch and mouse only? Recommended: two octaves, plus computer keys later if asked.
- E. Presets as fixed numbers or editable afterwards? Recommended: editable; any control change shows "Custom".
