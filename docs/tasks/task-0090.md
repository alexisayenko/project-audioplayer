# Improve the iOS Up next and queue interactions

Give the compact Up next preview a soft, faded cue at its bottom and make the
preview non-tappable for now. Support swipe-left removal in both the compact
preview and the full Now playing queue. Reordering is available only in the
full queue, using an explicit drag handle; the compact preview does not reorder
songs.
