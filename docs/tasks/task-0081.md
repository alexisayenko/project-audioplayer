# New version available notice

> Alex: after a deploy an already open tab keeps running the old JS (a console error came from an old `_v/af7955defd` while live was `_v/de077bb1ce`), which makes bug reports confusing and keeps old bugs alive.

A tab compares the web version it loaded (the hash in its own `/_v/<hash>/` module URL) with the server's current one (`GET /version`, API-200) when it becomes visible, on focus and every 5 minutes while visible, and shows one non-blocking bar "A new version is available." with Reload and a dismiss button (WEB-157). Never reloads by itself, never touches playback, silent on failure, no network while hidden, guests included.
