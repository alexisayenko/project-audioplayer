# Migrate to electrophone.cc

Move the live site from `https://play.isayenko.net` to `https://electrophone.cc` on the same server and tunnel, dual-host first, redirect last. The step-by-step runbook with owners, rollbacks and risks is [tech/domain-migration.md](../tech/domain-migration.md); verification is `bash scripts/check-domain.sh electrophone.cc --old play.isayenko.net`.

## Progress (2026-10-14)

Phases 0-3 done 2026-10-14: zone active, dual-host check PASS, Google and Apple sign-in verified on electrophone.cc. Open: Phase 4 (iOS), Phase 5 (`PUBLIC_HOSTS`, HSTS, redirect; recommended after one week of clean operation), Phase 6. `check-domain.sh` song count now reads 200 on both hosts.

State 2026-10-14 (read-only checks): both hosts 200 on HTTPS and `/health`; http redirects to https (301, Cloudflare); no HSTS on either host; old host serves directly (no 308 yet); session cookie is Secure, HttpOnly, SameSite=Strict, host-only (no Domain); `/auth/config` on the new host returns `apple_redirect` `https://electrophone.cc/`; `www.electrophone.cc` serves the app. Remaining steps: [domain-migration.md](../tech/domain-migration.md#remaining-steps-ordered).
