# Keep server covers on the phone for offline use

IOS-043: covers were fetched with the auth header and held only in a memory
cache, so they were blank offline after a relaunch. Now `CoverCache` keeps
the cover files on the phone for downloaded songs, never with a token in a
name or URL. Built and in TestFlight build 20261026; not checked on a device.

Remaining: check on a device that downloaded songs show their covers offline after a relaunch.
