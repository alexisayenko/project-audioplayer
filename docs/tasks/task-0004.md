# Keep server covers on the phone for offline use

IOS-043: covers are fetched with the auth header and held only in a memory
cache, so they are blank offline after a relaunch. Option: store the cover
file next to the audio when a song is downloaded, never with a token in its
name or URL. Revive when the blank covers bother the owner.
