# Deploy the YouTube title cut to the live server

The server now cuts the artist prefix and noise from YouTube titles (`server/app/titles.py`, applied in `server/app/extractor.py` `search`, `preview` and `download_audio`). Example: channel `RÜFÜS DU SOL`, title `RÜFÜS DU SOL ●● Innerbloom (Official Video)` becomes artist `RÜFÜS DU SOL`, title `Innerbloom`. The code is on `main` but not on the server that answers `https://play.isayenko.net`, so the iOS app and the web UI still show the raw title (seen in the Add sheet).
