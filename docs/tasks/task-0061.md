# Expandable Help menu in the sidebar

> Alex: add a new expandable menu item "Help" to the sidebar; collapsed by default; submenu "Music theory", "About", "Features".

## Decisions (owner, 2026-10-20)

- The submenu holds Music theory, About and Features, in that order. Clicking the Help header expands and collapses it. It is collapsed on every page load; the expanded state is not saved.
- AA1: About (`#/about`) and Features (`#/features`) are placeholder pages like Playlists ("... are coming soon").
- AB1: Music theory moves under Help; it leaves the main list. Its route `#/theory` and page are unchanged.
- AC1: Help is shown to everyone: signed-in users, guests and signed-out visitors (the three Help pages open without a session).

## Design decisions (agent, to confirm)

- Help takes the place Music theory had (between Song stats and Settings), so the phone tab bar keeps seven entries at the same width; no "More" item is needed.
- Collapsed by default on every load; navigating into a Help page by a link or the browser history expands it; reloading on a Help page shows it collapsed again.
- Wide rail: nested list expanding under the header, chevron rotates. Icon rail (64px, either width) shows one Help icon that opens a flyout with the three items. Phone tab bar: the Help entry opens a bottom sheet with the three items.
