## Method per review

Same as the goa and psytrance reviews: library check; web verification with readable URLs; caution with the "artist: title" tracklist form; an artist equal to the title is a red flag; up to 3 picks per role; a confidence level per pick; docs only first; saving to the catalogue only after the owner's go.
