# Expand the iOS playback dock into the Now Playing panel

Add a dedicated top-center grabber to the collapsed playback dock. Activating
it presents the existing Now Playing experience as a smoothly expanding
bottom panel; dragging the panel down collapses it. Keep the collapsed dock's
song row, controls and progress interaction intact, and keep the expanded
panel aligned with the existing Now Playing content and queue-preview
behavior. The desktop web player is out of scope.
