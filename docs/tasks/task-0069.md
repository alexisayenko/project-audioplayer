# About page: what Electrophone is and how it organises genres

> Alex: the Help > About page should explain how genres are structured. "We don't claim a standard. It's a consistent model for one library, and the documentation says where each decision came from."

## Scope

- `#/about` (`web/js/about.js`, replaces the "coming soon" placeholder, WEB-132) shows a short public text: what Electrophone is, how genres are organised (genres, groups, modifiers, four axes), four examples, and links to the documentation on GitHub.
- Visible to everyone, signed-out visitors included, so it holds no private information (no owner email, server addresses or library facts).
- The text lives in one exported data structure in `about.js` and states decided items only (ADR-0038, [genre-terminology.md](../tech/genre-terminology.md)); open decisions are not presented as facts. When the model changes, the text is edited there.
- Tokens-only styles in `web/about.css`; lazy route, tier 2 (WEB-121).
