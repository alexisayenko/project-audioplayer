# Playlists menu item and feature

New top-level "Playlists" menu item and feature. Requirements: [playlists.md](../specs/playlists.md) (PLS-001 to PLS-101). Decision: ADR-0022 (accepted). Reconciles [youtube-connect.md](../specs/youtube-connect.md) (YTC-030) and CAT-015. Planned; only the placeholder (PLS-100) is being built now.

## Phases

0. Placeholder: nav item "Playlists" between Library and Genres map, route `#/playlists`, empty page "Playlists are coming soon" (PLS-100, WEB-012).
1. Web basic: `playlists.json` store (DATA-110..112), `GET/POST/PATCH/DELETE /playlists`, `/playlists/{id}/songs` (add, remove, reorder), tree page with folders, drag and drop and "Move to...", row menu "Add to playlist..." picker and "Add to queue" rename (LIB-012), "Save queue as playlist", Play, Shuffle, Add to queue, guest read-only view, quotas, export (M3U8, CSV, JSON).
2. Import and Refresh: YouTube and SoundCloud links (yt-dlp), then Spotify public links (client credentials), then file import, then Connect YouTube creating playlists (PLS-042); `POST /playlists/import`, `/playlists/{id}/refresh`.
3. iOS read and offline play (PLS-090), smart playlists (PLS-091 to PLS-099), sharing (PLS-101).

## Decisions for Alex (recommendation first)

- D1 Delete of a non-empty folder: 1. ask, default "Move contents to parent" (recommended); 2. always delete contents; 3. always move.
- D2 Phone tab bar with six items: 1. six items, 60px each, short labels (recommended; fits 360px); 2. keep five and put Song stats and Genres map under a "More" item.
- D3 Same song twice in one playlist: 1. not allowed, second add ignored (recommended); 2. allowed.
- D4 Guest visibility: 1. all playlists public like the library (recommended, ADR-0018); 2. per-playlist "Public" flag, default private (needs a field and a UI toggle).
- D5 Fuzzy dedupe window for SoundCloud and Spotify: 1. normalised title + artist, duration within 3 s (recommended); 2. title + artist only.
- D6 Playlist caps: 200 nodes, 20000 entries in total, 5000 per playlist for non-owners (recommended); the owner is exempt.
- D7 Smart playlist rule shape: 1. `{match, conditions, sort, limit}` as in PLS-092 (recommended); 2. a saved Library URL query only (simpler, less expressive).

## Steps

1. Phase 0 placeholder (code agent, in progress).

3. Web: Playlists page, picker, queue wording, export; docs and CHANGELOG as each phase ships.
