# Synthwave terrain visualizer mode

A fourth visualizer mode `synthwave` ("Synthwave terrain") next to Mirrored spectrum, Ring and Terrain: one mode at a time, same switcher, keys and settings system. Visually a restyle of the WebGL Terrain. Requirements: [visualizer.md](../specs/visualizer.md#synthwave-terrain-planned) (VIZ-080 to VIZ-091). Web only.

## Dependency

Builds on the existing Terrain code and reuses where sensible: `viz-terrain-math.js`, `viz-terrain-gl.js`, `viz-lookahead.js` (timeline, future rows), `viz-beats.js`, LOD tiers, `viz-pacing.js`, `viz-modes.js`, `viz-panel.js`. Changes to Terrain itself must not alter its liked baselines (`terrain-liked-2`).

## Components and adjustable properties

1. Terrain grid (squares): speed toward the viewer, colours, square size.
2. Peaks: shape (smooth hills to sharp rocks), colours, fading speed, future silhouette (faint outline of the upcoming terrain ahead of the viewer; visibility and distance TBD).
3. Sun: colours (gradient allowed), radius, sectorization (start of the first slice, number of slices, slice sizes).
4. Sun haze: colour, radius, shape, movement.
5. Sun reflection on the ground: colour or gradient, opacity.
6. Horizon line: properties undecided.
7. Background space: colour, number of stars.
