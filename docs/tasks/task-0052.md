# Trim silence at the beginning and end of a song

> Alex: trim silence in the beginning and end of the song.

## Why

Many tracks (especially YouTube rips) start or end with seconds of silence, which breaks the flow between songs in the queue.

## Proposed behaviour

- Detect leading and trailing silence on the server (ffmpeg `silencedetect`, threshold about -50 dB, minimum about 0.5 s) and store it as `trim {start, end}` in seconds with the song; the audio file itself stays untouched.
- Players (web, iOS) start at `trim.start` and treat `trim.end` as the end of the song (next track starts there); the shown duration stays the file's real length unless decided otherwise.
- A Settings switch "Skip silence at the start and end" (default on) and a per-song override later.
- Detection runs after download, and as a one-off backfill for existing audio.
