# Mouse wheel over the dock changes the volume

> Alex: when the mouse pointer is over the dock panel, scrolling the mouse wheel controls the volume (wheel up = louder, wheel down = quieter).

One `wheel` listener on `#mini` (`web/js/dock-wheel.js`): 5 points per notch (pixel deltas accumulate, so touchpads and high-resolution wheels step smoothly), Shift = 1 point, clamped 0..100, through `player.setVolume` (slider, saved value, unmute). Ctrl and the dock's own menus are left alone; the page scroll is blocked only while the dock is shown. Inline feedback "62%" (WEB-115, `aria-live="polite"`, about 1 s), no toast.

Decision: the compact dock (PLY-149) still has its volume slider, so the wheel works there too; only a hidden dock (no song) is ignored.

Spec: PLY-150 in [playback.md](../specs/playback.md).
