# P2: Spotify metadata lookup and Add by Spotify link

Scope: server Spotify Web API client (client credentials, id and secret from the git-ignored env), `spotify-<id>` records, preview with "No audio yet", Add accepts Spotify links on web and iOS. Done when: pasting a Spotify track link saves a metadata-only record with cover, rate-limit and error cases show a clear message, no secret is logged or committed, and CAT-010..014 are implemented.

Depends on: task-0006. Specs: [`catalog.md`](../specs/catalog.md).
Gate: ADR-0010 must be Accepted before code starts.

## Progress (2026-10-13)

Done, preview slice (task-0006 not merged, so Save stops at the server):

- URL cleaning: `open.spotify.com/track/<id>`, `/intl-xx/track/<id>`, `spotify:track:<id>`,
  `spotify.link/<code>` (one https redirect, `open.spotify.com` only); `?si=` and tracking
  params dropped; album/playlist/artist/episode refused ("Only single tracks are supported").
  Server `urlclean.py`, web `url-clean.js` (+ node test), iOS `TagLogic.swift` (+ XCTest
  target `AudioPlayerTests`, `ios/Tests/UrlCleanTests.swift`). Id `spotify-<id>`.
- `server/app/spotify.py`: client-credentials token cached until expiry (60 s skew), one
  refresh on 401, 404 → `not_found`, 403 → `private`, 429 → `rate_limited` + Retry-After;
  mapping (title, artists joined primary-first, album, year, largest cover, duration, ISRC,
  primary artist genres → up to 3 `genre:` tags + `decade:`); keyless oEmbed fallback
  (`partial: true`) without credentials. Secrets never logged; `.env.example` placeholders.
- `POST /preview` accepts Spotify links: same shape, `source: "spotify"`, `audio: "none"`.
  `POST /songs` answers 422 `no_audio` for a metadata-only link until task-0006.
- Web Add dialog and iOS Add sheet: placeholder names Spotify, "No audio yet" note and chip,
  Save labelled "(no audio)", no download started, no "Save and play".
- Tests: `server/tests/test_spotify.py` (36, mocked network), node, XCTest.

Left: `POST /songs` metadata-only save (after task-0006), Library row state for `spotify-`
records, Get audio (task-0008+). The Spotify developer app and env values are Alex's manual
step (developer.spotify.com/dashboard → Web API, any redirect URI → `SPOTIFY_CLIENT_ID`,
`SPOTIFY_CLIENT_SECRET` in the server env).
