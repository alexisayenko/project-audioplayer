# Provision identification keys and fpcalc

The identification code is shipped ([task-0019](task-0019.md), [ADR-0013](../tech/decisions.md), API-070/071); it stays off until the server has the keys and `fpcalc`. Runbook: [deploy.md](../tech/deploy.md#identification-keys). Without a key the matching source is silently off; nothing else changes.

## Checklist for Alex

Never put a key in the repo, in chat or in a log; one file per credential.

1. Create an AcoustID application key: https://acoustid.org/new-application (free; needs an acoustid account).
2. Create a Discogs personal access token: https://www.discogs.com/settings/developers ("Generate new token").
3. On the PC store them for reference: `~/.config/acoustid/key.env` and `~/.config/discogs/token.env`, `chmod 600`.
4. On LXC 106 add to `/etc/audioplayer/env` (keep its mode, `root:audioplayer 640`): `ACOUSTID_API_KEY=...`, `DISCOGS_TOKEN=...`; optional `ACOUSTID_MIN_SCORE` (default `0.9`), `AUDIO_FPCALC` (default `fpcalc`).
5. Tell Claude "keys are in place" (never the values).

## Checklist for Claude (with Alex's approval)

1. In LXC 106: `sudo apt install libchromaprint-tools` (provides `fpcalc`).
2. `sudo systemctl restart audioplayer`.
3. Verify `fpcalc -version` prints a version.
4. `GET /songs/{id}/identify` status is available, not `unavailable`.
5. Run one identify on a known song; inspect the suggestions (MusicBrainz match, Discogs genres and styles).
6. Check the journal for rate-limit errors; confirm the limiters respect the Discogs limit (60 requests/min, limiter at 50) and the AcoustID limit (3 requests/s).

## Acceptance

- [ ] Identify returns `matched` plus suggestions for 3 sample songs.
- [ ] The keys appear nowhere: grep the journal (`journalctl -u audioplayer`) for each key value, without printing the keys; zero hits.
- [ ] `/health` is unchanged.
- [ ] Playback and offline use are unaffected.

## Rollback

Remove the two lines from `/etc/audioplayer/env` and `sudo systemctl restart audioplayer`; the sources go off silently. `fpcalc` can stay installed.
