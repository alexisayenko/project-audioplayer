# P8: ShazamKit Listen in the Add sheet

First step: verify the facts below against current Apple/vendor docs before building; they come from memory and are unverified.

Facts (unverified): ShazamKit's `SHSession` matches microphone audio against the Shazam catalog and returns title, artist, ISRC, artwork, genres and the Apple Music id; the ShazamKit App Service must be enabled on the App ID `com.alexisayenko.audioplayer` in the Apple Developer portal; the free tier and its limits, and whether the user's Shazam library can be written through `SHLibrary`, are unchecked.

Scope: a Listen button in the iOS Add sheet with a recording state and a result card; `NSMicrophoneUsageDescription`; a match creates a metadata-only catalog entry (id `applemusic-<id>`, or a `shazam-<id>` fallback), which the server only has to accept; needs network, so Listen is disabled offline. Manual step for Alex: enable the ShazamKit App Service on the App ID. Done when: a song playing nearby becomes a catalog entry without audio, the permission and no-match cases show a clear message, and CAT-043..046 are implemented.

Depends on: task-0006, task-0009 (Add sheet), task-0012 (Apple Music id handling). Specs: [`catalog.md`](../specs/catalog.md).
Gate: ADR-0010 must be Accepted before code starts.
