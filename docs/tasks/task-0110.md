# Studio Tools: Metronome

> Alex (2026-10-24): step 1 is only the synth; "the rest: create follow-up tickets".

Follow-up of [task-0106](task-0106.md). Nothing is built.

## Scope

- Tempo 20 to 400 BPM with a number field, nudges and **tap tempo**.
- Beats per bar 1 to 16, an accent choice per beat (accent, normal, off), the first beat accented by default.
- Sample-accurate clicks: a look-ahead scheduler on the Web Audio clock (`AudioContext.currentTime`), not `setTimeout` per click, so the tempo does not drift or jitter.
- Visual dots, one per beat, the current one lit; usable with the sound off.
- Optional haptic tick on phones where the browser allows it (the Vibration API is missing in iOS Safari; the native iOS tick belongs to [task-0113](task-0113.md)).
- Mixes with other audio: the song keeps playing, the metronome is a separate quiet output.
- Remembers tempo, beats per bar, accents and volume (browser storage, per viewer).

## Relations

- Tool on the Studio Analyze tab, like Live BPM (being built, 2026-10-24); a song's BPM already exists per song (see [task-0098](task-0098.md)).
- The Modify tab loop ([task-0072](task-0072.md)) is separate.

## Open questions (recommendations, not decisions)

- A. Click sound? Recommended: synthesised short clicks (accent higher), no sample files.
- B. Tap tempo averaging? Recommended: the last 4 to 8 taps, reset after 2 s of silence.
- C. A "Use song BPM" button that copies the playing song's BPM? Recommended: yes, as a button; never automatic.
- D. Subdivisions, time-signature denominators, count-in? Recommended: not in this task.
- E. Does it keep running when you leave the Analyze tab? Recommended: stop on leaving the tab.
