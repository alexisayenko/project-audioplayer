# Genres map: dragging only pulls, never pushes; a dropped circle stays put

> Alex: moving a parent node moves children on the diagram. Let's change it so it can only pull, not push. A dragged child gravitates back to its parent after release; stop that.

## Before

In `web/js/genre-force-view.js` dragging a parent moved its whole subtree rigidly (children kept their offset, so they also moved when the parent moved toward them), and the dragged node and its children still took part in charge and collision forces, shoving other circles. On release the dragged circle was unpinned, so the link springs pulled it back toward its parent.

## Done

- Tether: each descendant keeps the distance to its parent it had when the drag started; it is towed only once the parent is farther than that, and moving the parent closer or past it leaves the child where it is.
- The dragged circle and the circles towed with it are ghosts for the simulation (`ghost` in `genre-sim.js`): they neither repel nor collide with others, so dragging over a circle does not shove it.
- A dragged circle is pinned where it is dropped (`dropped`): no spring-back and no restoring force toward its parent. Reset layout and Saved layout release the pins.
- Tests in `web/js/genre-force-view.test.mjs`: tether (closer = child stays, away = towed within link length), no push, no spring-back.
