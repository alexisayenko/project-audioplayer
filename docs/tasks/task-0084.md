# Implement the iOS Library v5 GUI

Implement the four batches in [Library v5](../ui-ux/library-v5.md), using
Alex's Electrophone Screens iOS PDF export and the committed design tokens.
The dock / mini-player must remain unchanged (Alex, 2026-10-22).

Scope: app-level query and listening state; sorting and controls; rows and
Song Details; live filters and collapsing search; loading, offline and error
states; pinned headers on Settings, Statistics and Playlists.

Validation must distinguish source checks from a successful iOS build and
simulator/device checks. This checkout runs on Windows without Xcode.

## Implementation

All four source batches are written. `LibraryQuery` owns temporary query state
and saves sort/direction. `LibraryMatching` supplies pure search/filter/sort
logic. `ListeningStore` supplies optional authenticated data for Library and
Details, discarding responses from an older account/request. New components
use committed tokens and the sort SVG masters as template image assets.

Rows split playback, details and download into separate touch zones and expose
one VoiceOver element with custom actions. Details supplies facts, statistics,
sharing and confirmed deletion (remote first, 404 accepted, queue removal).
The current song cannot be removed through Edit. The Settings, Statistics and
Playlists changes only pin their headers. The dock, drawer, Now playing,
shared component styles and generated tokens have no changes.
