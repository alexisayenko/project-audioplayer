# Migrate the iOS app and web UI to the Electrophone design system

ADR-0009 makes the Design System artifact the single source of truth and
lands `DesignTokens.swift` + `web/tokens.css` as generated consumers. Nothing
uses them yet.

iOS:
- Replace `Theme.swift` tokens with `DS.Color` / `DS.Font` / `DS.Space` /
  `DS.Radius`; delete the walnut, chrome and piano-key code once no view
  references it.
- Rebuild `Components.swift` from the system's component READMEs:
  Transport tray, category Chip + FilterSheet, Segment, TabBar, SongRow,
  Button. Match the "Electrophone Screens" artboards (Library, Add,
  Playback day/night, Settings, Library filter sheet).
- Library: four category chips (Tags, Genres, Years, Countries → plain,
  `genre:`, `decade:`, `country:`) opening a bottom sheet; `lang:` folds
  into Tags until a fifth chip is wanted.
- Deck on Playback: platter, tonearm following progress, red LED, copper
  frame — from tokens, no textures.
- Day/night follow the system appearance; check 4.5:1 on every text/ground pair.
- New app icon from the system (Vega icon retired).

Web:
- Link `tokens.css` from `index.html`; rewrite `style.css` on its
  variables (`--ground`, `--surface`, `--accent-ink` …) and `.t-*` styles.
  Same category-chip filter as iOS.

Done when no hex value remains in `ios/Sources` or `web/style.css` outside
the generated files.
