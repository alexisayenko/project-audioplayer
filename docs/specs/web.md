# Web UI

Code: `web/js/*.js` (module map: [architecture.md](../tech/architecture.md#web-ui-web); the sign-in is in `settings.js`, `api.js`, `app.js`; the player in `player.js` and the pure `queue-logic`, `scrub`, `dl-queue`, `dl-progress`, `playable`, `reveal`, `sidebar-state` modules; the Genres map in `genres.js`, `genre-*.js`; the visualizer terrain mode in `viz-terrain-math.js`, `viz-terrain-gl.js` and `viz-modes.js`, wired into the mode switch, WEB-064, VIZ-040); server side in
[api.md](api.md) (API-020..024) and ADR-0006. Status values reflect code read
on 2026-10-13 (the web is a catalog UI: it saves song entries and fetches audio only on demand, WEB-034 and WEB-036); the session sign-in flow was seen live on 2026-10-14 (server journal: 6 successful `POST /auth/session`, 5 user profiles); which provider was used is not recorded.

- WEB-001 MUST: a signed-out visitor (no session) sees only Settings; Library, Playback and the player bar are hidden and routed away. Status: implemented

Status: implemented (session sign-in seen live in the server journal)
- WEB-003 MUST: the ID token goes once to `POST /auth/session` and is never stored by the page or put in a URL; afterwards the HttpOnly session cookie authenticates, and audio and cover URLs carry no token. Status: implemented (session sign-in seen live in the server journal)

- WEB-017 MUST: every web asset is served under a versioned path so a deploy never waits for a browser or CDN cache. `GET /` and `GET /index.html` return `index.html` with `tokens.css`, `style.css`, `favicon.svg` and `js/app.js` rewritten to `_v/<version>/...` (`Cache-Control: no-cache`, `ETag` = version, 304 on `If-None-Match`); `GET /_v/<version>/<path>` serves the file with `public, max-age=31536000, immutable` when `<version>` is current and `no-cache` otherwise; relative imports inside `js/` therefore resolve under the same versioned path. `<version>` is a hash of the names, sizes and mtimes of all files in `web/` (`web_version()` in `server/app/web.py`).
