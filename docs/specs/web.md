# Web UI

Code: `web/js/*.js` (module map: [architecture.md](../tech/architecture.md#web-ui-web); the sign-in is in `settings.js`, `api.js`, `app.js`; the player in `player.js` and the pure `queue-logic`, `scrub`, `dl-queue`, `dl-progress`, `playable`, `reveal`, `sidebar-state` modules; the Genres map in `genres.js`, `genre-*.js`; the visualizer terrain modes in `viz-synth-*.js`, `viz-terrain-math.js`, `viz-terrain-gl.js` and `viz-modes.js`, wired into the mode switch, WEB-064, VIZ-040); server side in
[api.md](api.md) (API-020..024) and ADR-0006. Status values reflect code read
on 2026-10-13 (the web is a catalog UI: it saves song entries and fetches audio only on demand, WEB-034 and WEB-036); the session sign-in flow was seen live on 2026-10-14 (server journal: 6 successful `POST /auth/session`, 5 user profiles); which provider was used is not recorded.
