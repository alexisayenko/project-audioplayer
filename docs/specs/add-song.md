# Add song

Code: `web/js/add.js`, `server/app/routes/lookup.py` (`preview`), `server/app/routes/songs.py` (`create_song`), `server/app/downloads.py` (`run_download`), `server/app/extractor.py`, `server/app/titles.py`, `server/app/metadata.py`, `server/app/bpm.py`.

## Flow

1. Paste a YouTube URL, press Preview (`POST /preview`).
2. Edit fields and tags in the preview card.
3. Web: "Save to library" saves metadata only (`POST /songs` with `audio:false`, 201, no download, no polling); toast "Saved to library". Audio reaches the server only through the iOS download flow (2026-10-13). The steps below describe the iOS/server download path (`audio` omitted: 202, poll `GET /songs/{id}/status`).

## BPM

- ADD-020 MUST: BPM is optional; empty means auto-detect after download (web: no BPM input, a muted line "BPM is detected after saving"; iOS: a muted line "BPM is detected after saving"); a supplied value (20..300, whole number, fractions rounded) is kept and skips detection. Status: implemented
- ADD-021 MUST: detection decodes the saved file with `ffmpeg` to mono 44.1 kHz float PCM (120 s timeout), runs aubio tempo, takes the median of per-beat estimates (needs >= 4 beats), folds into 70..180 and rounds to a whole number. Status: implemented
- ADD-022 MUST: any detection failure (no ffmpeg, no aubio, too few beats) is logged and stored as `bpm: null`; it never fails the download. Status: implemented
- ADD-023 MUST: BPM is a heuristic and may be off by half or double; the UI says so and lets the user edit it or re-detect from the Edit dialog (`POST /songs/{id}/bpm/detect`). Status: implemented
- ADD-110 MUST: songs added before detection existed (or whose detection failed) can be filled in bulk with Settings > BPM detection > Detect missing BPM (API-110..112); it uses the same detector, rounding and octave heuristic as the download path (ADD-022, ADD-023). Status: implemented
- ADD-024 SHOULD: detection run off the request path for slow files. Status: implemented (the job runs in a background task; re-detect runs in a thread pool)
