# Studio site

The Analyze and Synthesize tools as a public static site at https://studio.electrophone.cc ([ADR-0049](../tech/decisions.md), owner decision GR1, 2026-10-24, [task-0114](../tasks/task-0114.md)). The site is live (2026-10-24, task-0114 phases 1 and 2): Pages project `electrophone-studio`, custom domain `studio.electrophone.cc` with a proxied CNAME; the main app links and redirects to it and no longer has the two tabs (STU-016, phase 3, owner decision GU1, 2026-10-24). The tools themselves are specified in [web.md](web.md) (WEB-150 to WEB-202) and ADR-0048; this file says only what changes by moving them. Modify (the former Track tab) stays in the main app.

## Site and build

- STU-001 MUST: the site is static files (one HTML page, one hashed JS file, one hashed CSS file under `assets/`, the favicons, `_headers`, `robots.txt`) served by Cloudflare Pages (Direct Upload, project `electrophone-studio`) at `https://studio.electrophone.cc`; no server code, no API call, no sign-in, no cookie, no analytics, no third-party request. Status: deployed 2026-10-24

Status: deployed 2026-10-24
