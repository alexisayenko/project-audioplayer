# Synthwave references

Alex's reference images for the Synthwave presets ([VIZ-092](../../specs/visualizer.md#synthwave-presets), [task-0031](../../tasks/task-0031.md)). They are third-party stock images (one carries a Shutterstock mark) and the repo is public, so they are git-ignored and stay on Alex's machines only. Only this README is committed.

| File | Preset |
|------|--------|
| `00-collage.webp` | Collage of ten images (the original brief; not a preset) |
| `01-blue-valley.webp` | Blue valley |
| `02-teal-dunes.png` | Teal dunes |
| `03-neon-peaks.png` | Neon peaks |
| `04-violet-plain.png` | Violet plain |
| `05-midnight-grid.png` | Midnight grid (has a skyline, deferred) |
| `06-neon-sea.png` | Neon sea |
| `07-sunset-8bit.png` | 8-bit sunset (colours and objects only) |
| `08-retro-dusk.png` | Retro dusk (colours and objects only) |

The preset thumbnails are screenshots of our own renderer (`web/img/synth-presets/`), never these images.
